# Nova v2.0.0 — Production Release Notes

We are thrilled to announce the official stable release of **Nova v2.0**!

Nova v2.0 is a distributed, offline-first AI ecosystem that pairs your Linux computer with your Android smartphone (optimized for Samsung Galaxy A13).

---

## Key Highlights

- 📱 **Full Phone Automation**: Launch apps, auto-play YouTube videos, make WhatsApp calls, take screenshots, perform touch gestures.
- 🎙️ **Remote Audio & Voice Mode**: 16 kHz PCM remote mic capture, TTS speech playback through phone speaker, instant voice transcription.
- 📊 **Device Management & Diagnostics**: Real-time RAM, CPU, Storage, Battery, Logcat diagnostics, and secure File Manager.
- 🛡️ **Hardened Security**: JWT pairing authentication, AES-256-GCM encryption, Android KeyStore, and ADB command guards against dangerous executions.
- 🧪 **100% Test Pass Rate**: 83 automated test cases passing across all companion test suites.
