# Changelog

All notable changes to Nova will be documented in this file.

## [3.0.0] - 2026-08-05

### Added
- **Phase 1 (Mobile Foundation)**: Foreground service, `MobileCoreManager`, `LifecycleManager`, event bus, dashboard UI.
- **Phase 2 (Wake Word Engine)**: Offline "Hey Nova" engine, sliding window scoring, energy thresholding.
- **Phase 3 (Voice Pipeline)**: Audio recorder, state machine, transcription pipeline.
- **Phase 4 (Local Command Engine)**: 25+ local intents, parameter extraction, plugin dispatcher.
- **Phase 5 (Hybrid AI Router)**: Capability matching, target selector, Nova Core discovery probing.
- **Phase 6 (Personal Memory)**: Category store, frequency tracking, learning listener, sensitive key guard.
- **Phase 7 (Smart Automation)**: 16 trigger types, condition engine, action executor, routine repository, routine manager.
- **Phase 8 (Multi-Device Sync)**: Device registry, payload checksums, 5 conflict policies, session continuity, offline queue.
- **Phase 9 (AI Skills Framework)**: Skill manifest, loader, executor, sandbox context, permission approval queue, 9 built-in skills.
- **Phase 10 (Production Hardening)**: Latency benchmarking, Samsung battery optimization, full doc pack, production test suite.

## [2.0.0] - 2026-08-04

### Added
- Android companion plugin system, remote ADB automation, remote audio capture, device management dashboard.
