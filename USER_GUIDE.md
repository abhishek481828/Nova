# Nova v2.0 — End User Guide

Welcome to Nova v2.0! This guide explains how to interact with Nova using voice commands and natural language text.

---

## 1. Quick Start

Start Nova:
```bash
./start.sh
```

---

## 2. Phone Commands Cheat Sheet

| Category | Example Prompts |
| :--- | :--- |
| **Microphone Control** | `mic on`, `open mic`, `mic off` |
| **Voice Mode** | `start voice session`, `stop voice session` |
| **YouTube Playback** | `open youtube and play shape of you` |
| **WhatsApp Calling** | `call Pankaj on whatsapp` |
| **Screen Control** | `take screenshot`, `scroll down on phone`, `go home on phone` |
| **Device Info** | `device info`, `device health`, `device storage`, `device memory`, `device battery` |
| **Volume Control** | `set phone volume 80` |
| **Flashlight** | `turn on flashlight`, `turn off flashlight` |

---

## 3. Keyboard Shortcuts

- `exit` or `quit`: Exit Nova CLI REPL.
